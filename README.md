# קפיצה גדולה

פלטפורמר דו-ממדי בעברית, שנבנה ב-Unity.

- דף ההורדה: https://israelb014.github.io/kfitsa-gdola/
- קרדיטים ורישיונות: [CREDITS.md](CREDITS.md)
- הקבצים הבינאריים נשמרים ב-Git LFS, לכן צריך להתקין אותו לפני שמשכפלים את המאגר.

## בדיקות

- שלבים: `python3 tools/make_levels.py Assets/Resources/Levels`
- בדיקת הגעה לשלבים: `tools/validate.sh`
- כל בנייה רשמית מריצה את בדיקת ההגעה ונכשלת אם משהו לא ניתן להגעה.
