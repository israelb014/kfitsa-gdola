# תוכנית הפרסום ב־itch.io

הדף: https://israelb014.itch.io/kfitsa-gdola

## מה כבר מוכן בתיקייה הזאת
- cover.png: תמונת שער 630x500
- screenshots/: חמישה צילומי מסך 1920x1080 מהמשחק עצמו (1-1, סופת החול, כניסת ענק הכפור, מתחת לים, חנוכה)
- short_description.txt: שורת תיאור קצרה בעברית ובאנגלית
- description_he.md ו־description_en.md: התיאור המלא
- tags.txt: עשר תגיות
- form_fields.txt: מה נכנס בכל שדה בטופס

## הסדר כשהמשתמש ליד המחשב
1. ~/work/_tools/itchweb/open.sh פותח חלון Chrome גלוי, בפרופיל נפרד (לא הפרופיל הרגיל), בדף ההתחברות של itch.io.
2. המשתמש לוחץ "Log in with GitHub" ומאשר בעצמו. אני לא מקליד שום סיסמה.
3. Dashboard > Create new project. ממלאים לפי form_fields.txt, מעלים את השער ואת חמשת צילומי המסך ושומרים כטיוטה (Draft).
4. butler login: הפקודה מדפיסה כתובת אישור. פותחים אותה באותו חלון ולוחצים לאשר.
5. tools/itch_push.sh מעלה את Linux, Windows ו־Android לערוצים linux, windows ו־android.
6. בדף העריכה מסמנים לכל קובץ את הפלטפורמה שלו, אם itch לא סימן אותה לבד.
7. משנים את Visibility ל־Public ושומרים.
8. בודקים מחלון רגיל (בלי התחברות) שהדף נפתח ושכל אחד משלושת הקבצים יורד, ומשווים את הגודל לקבצים שנבנו.
9. שולחים למשתמש את הקישור.

## מה לא נוגעים בו
הגדרות החשבון, אימייל, תשלומים ופרויקטים אחרים. אם itch מבקש משהו כזה (למשל אימות אימייל או פרטי תשלום לתרומות), עוצרים ושואלים את המשתמש.
